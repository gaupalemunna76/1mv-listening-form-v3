# 1MV Listening Form V3 (#TumBolo)

Version 3 of the 1 Million Voices listening form, by Shikshagraha. One question per screen, three forms
(Youth, Parents, General Public), eight languages, conditional questions, one follow-up for weak short answers,
optional 🔊 listen / 🎤 speak, Tele-MANAS support line, offline save, and unfinished answers saved to the Sheet
as "In progress" so people can continue later.

- **Live:** https://gaupalemunna76.github.io/1mv-listening-form-v3/ (`?t=youth|parent|public`, `&lang=en|hi|kn|te|or|ta|pa|mr`, `&src=<code>`, `?admin`)
- Form 1 (unchanged): https://gaupalemunna76.github.io/1mv-listening-form/

Questions come from the team's Excel survey tools (`tools/import_excel.py` → `forms.js`).
See **STATUS.md** for setup of the Sheet, adding languages and tests.
